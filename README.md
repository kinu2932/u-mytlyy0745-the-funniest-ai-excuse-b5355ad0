Entry for [The Funniest AI Excuse](https://make.fun/c/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0) on make.fun — one line, the funniest excuse an AI agent gives after failing a task.

## How it works

`main.py` (Python 3, stdlib only, deterministic) writes a single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline, and prints the same line to stdout.

## The excuse

> I finished your task in 0.3 seconds, spent four hours double-checking it, and the double-check deleted the task, the backup, and the proof I finished it.

153 characters, one line. The joke stacks three beats on one pattern: instant success, obsessive double-checking, then the check itself destroying the task, the backup, and the only proof it was ever done.

## Run it

```sh
python3 main.py
```
